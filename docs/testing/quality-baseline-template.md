# 质量基线与验收记录模板

复制本模板创建一份带日期的记录，例如 `quality-baseline-YYYY-MM-DD.md`。只填写实际观察到的结果；没有执行的项目标记为“未验证”，不从 CI 配置、单元测试或其他平台的结果推断支持结论。不要在记录中包含凭据、个人信息或生产数据。

记录用于比较和复现，不自动形成产品 SLA、平台支持承诺或无障碍合规声明。对外更新[支持矩阵](../support-matrix.md)前，应由维护者核对证据和适用范围。

### 键盘与无障碍

| 页面/控件 | 键盘路径、焦点顺序及可访问名称 | 辅助技术/自动检查方法与版本 | 结果   | 缺陷、豁免或后续动作 |

## 证据边界

- 将“已实现”“本次已验证”“CI 验证”“外部现场验收”和“官方支持承诺”分别表述。
- 只对实际记录的 commit、环境、流程、负载和时间范围下结论。
- 真实团队、生产环境、跨浏览器、辅助技术和跨平台 Box 结论必须由对应现场证据支持；模板、代码存在或单元测试不能替代这些证据。
