# ReqFlow 前端界面说明

## 布局

顶部导航（56px 固定）+ 左侧菜单（232px）+ 内容区 + 右侧面板（300px，<1280px 隐藏）。
整体骨架参照产品原型，视觉按"克制深色"落地。

| 区域     | 内容                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| 顶部导航 | 品牌标记、全局搜索（⌘K 聚焦）、用户信息、退出登录                                          |
| 左侧菜单 | 控制台 / 项目列表 / AI 运行 / 需求管理 / PRD / 知识库 / 追溯 / 用户中心，底部 API 连接状态 |
| 内容区   | 页面标题 + 欢迎语，下方为各业务页内容                                                      |
| 右侧面板 | 快捷操作（新建需求 / 项目列表 / 添加知识）+ 使用说明                                       |

## 设计取舍

- 深色表面分三层：应用底 `#0b0d10`、卡片 `#14171d`、悬停 `#181c23`，统一 1px 描边 `#232830`。
- 单一强调色 `#4c7dff`，只用于主按钮、当前菜单、进度条与关键数据。
- 不使用粒子背景、鼠标光晕、发光阴影、渐变文字和装饰动画；图标统一用 `lucide-react` 线性图标。
- 状态用文字色区分：评审中（琥珀）、进行中（蓝）、已完成（绿），其余中性灰。

## 代码位置

- 布局与导航：`apps/web/src/App.tsx`
- 全局样式：`apps/web/src/index.css`
- 控制台：`apps/web/src/pages/Dashboard.tsx`（数据来自 `dashboardApi.summary()`）
- AI 运行页面：`apps/web/src/pages/Runs.tsx`，提供产品需求发现四步流程、持久化消息时间线、草稿确认和 SSE 更新。

## 验证边界

AI 运行页面依赖登录态和项目权限。离线测试使用固定 provider；真实 Claude 调用、PostgreSQL 持久化和浏览器端完整验收需要在隔离本地环境单独执行。
