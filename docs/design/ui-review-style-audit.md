# UI 样式与可读性审计

## 本轮统一收口：当前结论优先于下方历史记录

本轮边界是用户确认的原始 32 项页面审查中的 #26、#27，以及 #15/#29 修改需要的回归；
workspace onboarding / T1–T11 不在本次范围。验收以当前页面和交互状态为准，不要求全仓库清零旧 CSS。
下方保留的早期记录是过程快照，其字号计数、未核验范围及“运行事件必须使用真实后端”的推断
均已被本节取代，不能再作为本轮结论。

### 构建与级联的实际关系

`apps/web/src/main.tsx` 的顺序为：
`index.css → ui-v2.css → ui-v3.css → ui-v4.css → tokens.css → feedback.css → task-state.css →
workflow-dialog.css → requirement-detail.css → mobile-lists.css → project-detail.css →
decision-drawer.css → workbench-mobile.css → shell.css → contrast.css → confirm.css → foundations.css`。

四个旧文件仍参与构建。`foundations.css` 把旧变量映射到 `--wm-*`，并提供基础组件的最终表面、
边框、字体、圆角、阴影及焦点环。页面的布局、状态选择器和断点仍由原文件及页面 CSS 承担；
例如流程任务的等待态虚线边框和阻塞态边框仍按状态保留。`ui-v3.css` 中的深色变量随后被
`ui-v4.css` 和基础层覆盖，当前没有独立深色主题入口；保留 v3 文件的理由是仍在使用的工作台
结构和动画，不是已经验收了一个隐藏的深色产品模式。

  通知操作者/时间、Agent 命令。分别由 foundations、v4 末尾可读性规则、requirement-detail、
  confirm、Profile/Knowledge 页面样式等接到 12px 或 14px；本轮补充的动态证据与权限夹具用于

1. 当前没有 Runs 页面和路由，因而没有可构造的运行记录页面验收；相关无引用 CSS 已删除。

   独立检查结果。
3. 未进行实体设备、Safari/Firefox、系统强制高对比度模式或所有历史定义/工件 MIME 的人工验收。
   此次 Chromium 四视口验证和专项逻辑测试不能冒充这些环境。
4. 无全仓库“零旧规则/零小字号”承诺；本轮保留规则的用途以上表为准，不再以“可能有未知深链接”

## 语义字号

- 正文和任务标题使用 `--wm-text-md`（14px）或更大字号。
- 次要信息、状态、责任角色、阶段轨道和卡片元数据使用 `--wm-text-xs`（12px）或 `--wm-text-sm`（13px）。
- 流程图里保留 9px/10px 的旧样式只用于短编号或头像首字等装饰性标记；任务标题、责任人、等待提示和状态通过 `requirement-detail.css` 的页面覆盖提升到 12px/14px。成员芯片、阶段编号、泳道统计和证据提示也有可见文字，不依赖颜色或极小字号。
- 本轮审计范围内，低字号规则统计为：`requirement-detail.css` 仍有 1 条 9px 头像首字规则；`workbench-mobile.css`、`Profile.tsx`、`Roles.tsx`、`ProjectPipelineOverview.tsx` 均无 9/10/11px 规则。旧主题层仍有 `index.css` 36 条、`ui-v2.css` 2 条、`ui-v3.css` 13 条、`ui-v4.css` 32 条 9/10/11px 声明，未在本轮机械替换。
- `ui-v4.css` 的流程图低字号声明仍保留作兼容回退，但同名流程组件随后由 `requirement-detail.css` 提升到 12px/14px；阶段圆点序号和头像首字属于短装饰标记，可保留 9px。其余旧主题选择器尚未逐一确认引用关系，不能宣称全仓字号迁移完成。
- 移动卡片元数据允许换行，避免 `nowrap + ellipsis` 把负责人、下一步或缺失数据提示隐藏。

## 令牌迁移

流程团队区已经有一组页面级 token 覆盖：表面、边框、强调色、危险色、圆角、阴影和键盘焦点环均来自 `styles/tokens.css`。需求、评审、成员和凭据窄屏卡片的基础层也已切换到同一组 `--wm-*` 令牌，作为一个完整移动列表组件族迁移。`ui-v4.css` 仍保留旧规则作为兼容回退；后续应在浏览器回归确认后，按组件组删除已被覆盖且无其他页面使用的重复声明。

基础组件层已由 `styles/foundations.css` 落地，并在 `apps/web/src/main.tsx` 中放在令牌、页面专属样式和旧主题层之后导入。该层把应用背景、导航/侧栏/抽屉、按钮、表单控件、卡片、表格、状态标签和统一焦点环接到 `--wm-*` 令牌，同时保留页面级状态色、布局、动画和移动断点。它是 #26 的实际基础层迁移；由于旧的 `index.css`、`ui-v2.css`、`ui-v3.css` 和 `ui-v4.css` 仍被保留，当前仍不能宣称全仓库 CSS 已完成迁移。

本轮未把全仓库旧 CSS 一次性替换成 token，也没有改动未验证的通用选择器。这样可以继续保留现有流程动画、状态色和桌面布局行为，同时让需求详情页在 1440/1024/640/390 像素视口逐步收敛到同一套令牌。
