# WorkMesh UI v4：亮色指挥台

> 版本：v4.0 · 日期：2026-11-03 · 状态：默认主题
> 关系：v3 负责“指挥台”结构（任务头/频谱/读数环/右栏/动效），v4 只把它从深色切成亮色。
> 实现：`apps/web/src/ui-v4.css`，在 `ui-v3.css` 之后加载。

## 1. 为什么是亮色

深色指挥台有冲击力，但 WorkMesh 是白天长时间读证据、签字的工作台。大面积深色会让表格、正文、表单对比度变差，也容易显得“监控大屏”而不是“工作系统”。

v4 的目标是：

- 保留指挥台的结构和密度；
- 用亮色表面保证长时间阅读；
- 用青色信号、等宽编号、网格底纹保留科技感；
- 深色只留在小面积代码块（CLI）里做对比。

## 2. Token

| 用途         | 值                           |
| ------------ | ---------------------------- |
| 应用底       | `#f3f6fb`                    |
| 面板         | `#ffffff`                    |
| 描边         | `#e2e8f0` / 强描边 `#cbd5e1` |
| 主文字       | `#0f172a`                    |
| 次文字       | `#475569`                    |
| 辅助文字     | `#7b8aa0`                    |
| 主信号（青） | `#0891b2`                    |
| 审批（蓝）   | `#2563eb`                    |

| 可开工（绿） | `#059669`                    |
| 危险（玫红） | `#e11d48`                    |

主按钮青→蓝渐变；危险按钮白底红边；代码/CLI 块保留深色。

## 3. 结构保留

- 顶栏遥测：`AUTHORITY LINK` + 实时时钟；
- 工作台任务头：`OPEN SIGNALS` 大数字 + 待办频谱；
- 四张读数卡：01–04 编号 + 右上角占比环；
- 工作台双栏：信号流 + `SYSTEM STATUS / ACTIVITY FEED / CLI`；
- 门禁 01–07 编号、扫描光带、状态脉冲；
- 动效在 `prefers-reduced-motion` 下关闭。

## 4. 亮色下的约束

1. 正文、表格、表单必须在白底上达到可读对比度，不用浅灰字做正文。
2. 发光只保留在：当前门禁、主按钮、焦点、通知徽标、状态点。
3. 网格底纹透明度不超过 4%，避免像草稿纸。
4. 代码块、CLI 命令可以用深色底，作为“终端窗口”的小面积对比。
5. 后续如需夜间模式，v4 作为亮色主题、v3 作为暗色主题切换，不再新建第三套。
