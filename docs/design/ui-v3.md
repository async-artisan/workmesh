# WorkMesh UI v3：签字指挥台

> 版本：v3.0 · 日期：2026-11-03 · 状态：已落地
> 目标：在 v2 的成熟布局上，补足“冲击力”和“科技感”，但不牺牲可读性与操作边界。
> 实现：`apps/web/src/ui-v3.css`，在 `ui-v2.css` 之后加载，只换视觉层，不改布局与 API。

## 1. 视觉判断

v2 解决了“像后台”的问题，但整体仍是白底灰边的通用管理台。WorkMesh 的定位是**人给 AI 交付签字的地方**，界面应该像一个“指挥台”：

- 深色工作区，让证据、编号、状态成为主角；
- 青色信号表示“需要你处理”，琥珀色表示变更，绿色表示可开工；
- 网格底纹和等宽编号提供“系统在运行”的感觉；
- 发光只用于当前项、主操作、焦点，不整页乱发光。

## 2. 颜色

| 用途 | 值 |
| --- | --- |
| 应用底 | `#060a12` |
| 面板 | `#0c1524` |
| 顶栏 | `rgba(7,12,21,.9)` + 模糊 |
| 描边 | `#1a2a40` / 强描边 `#2a405c` |
| 主文字 | `#e8eef8` |
| 次文字 | `#a8b8ce` |
| 辅助文字 | `#6f839d` |
| 主信号（青） | `#22d3ee` |
| 变更（琥珀） | `#fbbf24` |
| 可开工（绿） | `#34d399` |
| 危险（珊瑚） | `#fb7185` |

主按钮使用青→蓝渐变；危险按钮不铺满红色，只做红边 + 浅红底。

## 3. 底纹与层级

- `body` 固定背景：左上青色径向光、右上蓝色径向光、32px 网格线；
- 面板是半透明深色渐变 + 1px 信号边，不靠大阴影堆层级；
- 表格头使用近黑底 + 等宽小字，数据行保持 13px；
- 所有编号（需求编号、workflowKey、hash）使用等宽字体与青色；
- 卡片 hover 只加“青色边 + 轻微外发光”，不位移。

## 4. 页面规则

### 工作台

- 四张读数卡顶部一条青色渐变线；数字使用白→青渐变；
- 签字行左青、变更行左琥珀、可开工行左绿；
- 主操作渐变按钮，次操作暗色描边按钮；
- 分组标题用等宽大写小字，像系统分区。

### 看板

- 列底近黑，卡片略亮；hover 青边；
- 不引入拖拽，不改变“只读执行视图”。

### 需求详情

- 标题右侧加一个青色状态点，强调“当前对象”；
- 门禁当前节点青边 + 微光；已完成节点绿点；
- Tab 激活态青色下划线 + 微光；
- 交付物、变更、PRD、追溯沿用 v2 结构，只换深色表面。

### 弹层

- 遮罩加深 + 背景模糊；
- 抽屉/弹窗深色面板，边框使用信号色；
- 通知、用户菜单、更多菜单同一套深色面板。

## 5. 约束

1. 发光只用于：当前门禁、主按钮、输入焦点、通知徽标、状态点。
2. 不使用大面积纯黑 `#000`，保留蓝黑层次。
3. 不使用彩虹渐变；只保留青→蓝一条主渐变。
4. 正文对比度优先，辅助文字不低于 `#6f839d`。
5. 表格、表单、按钮尺寸沿用 v2，不因换主题改变密度。

## 6. 与 v2 的关系

- v2 负责布局、间距、内容最大宽度、表单/表格密度；
- v3 只覆盖颜色、表面、字体细节、发光与底纹；
- 旧页面 class 不变，后续新页面直接继承 v3 token；
- 如果以后要提供浅色模式，应以 v3 为暗色主题、v2 为亮色主题做切换，而不是再写第三套。
