# 安全事件响应记录模板

> 这是内部或受控存储用的记录模板。不要把可利用漏洞细节、真实凭据、生产数据、未脱敏日志或攻击样本提交到公开 Git 历史、issue、PR 或发布附件。公开披露应依据 [SECURITY.md](../../SECURITY.md) 和维护者批准的披露计划进行。

## 记录元数据

| 字段                | 内容                                                  |
| ------------------- | ----------------------------------------------------- |
| 事件编号            | `SEC-YYYY-NNN`                                        |
| 首次接收时间（UTC） | `YYYY-MM-DD HH:MM`                                    |
| 报告渠道            | 私密漏洞报告 / 受控邮箱 / 受控工单 / 其他（注明）     |
| 记录位置            | 受控系统链接；不要填写公开 issue 或 PR                |
| 当前状态            | 新建 / 分级中 / 缓解中 / 修复验证中 / 已披露 / 已关闭 |
| 记录负责人          | 真实姓名或组织账号；未确认时填写“待管理员指定”        |
| 备份负责人          | 真实姓名或组织账号；未确认时填写“待管理员指定”        |
| 最近更新时间（UTC） | `YYYY-MM-DD HH:MM`                                    |

- 可复现前置条件：

## 验证清单

- [ ] 修复测试覆盖报告的触发条件和权限边界。
- [ ] 在隔离环境完成回归；记录 OS、Node.js、数据库和部署方式。
- [ ] 验证正常流程未被破坏。
- [ ] 验证项目隔离、认证、授权、审计日志和错误响应没有泄露敏感信息。
- [ ] 验证迁移、备份恢复和回滚路径（如适用）。
- [ ] 验证已轮换或撤销受影响凭据，并确认旧凭据失效。
- [ ] 记录测试命令、CI run、制品摘要和结果。

## 脱敏检查

- [ ] 已移除密码、token、Cookie、私钥、连接串和有效会话。
- [ ] 已移除生产数据、个人信息和第三方机密。
- [ ] 公开材料没有攻击步骤、利用代码或可直接复现的敏感请求。
- [ ] 公开 commit、issue、PR 和附件只引用安全摘要和修复信息。
- [ ] 原始材料保存在访问受限的系统，并有保留期限和访问审计。
