# 外部团队验收记录模板

> 用于记录真实外部团队在获准环境中的使用验收。匿名化团队名称即可，但必须保留授权、部署 commit、时间线、指标、缺陷和签字证据。仓库维护者的本地测试团队不能代替外部验收；未发生的使用不得填写为通过。

## 团队与授权

| 字段             | 内容                            |
| ---------------- | ------------------------------- |
| 团队标识         | 匿名化名称或受控编号            |
| 授权方           | 真实组织/负责人，受控记录中填写 |
| 授权范围         | 环境、数据、成员和允许的操作    |
| 验收负责人       |                                 |
| 维护者陪同人     |                                 |
| 验收时间（UTC）  |                                 |
| 是否允许公开引用 | 是 / 否 / 仅匿名汇总            |
