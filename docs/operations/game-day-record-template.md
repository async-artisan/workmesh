# 运维演练记录模板

> 用于备份恢复、迁移、回滚、故障缓解和 readiness 演练。记录真实环境、实际耗时和证据；没有实跑的项目填写“未执行”，不要用预估值替代结果。生产演练应使用批准的变更和受控数据。

## 演练元数据

| 字段                   | 内容                                                     |
| ---------------------- | -------------------------------------------------------- |
| 演练编号               | `OPS-YYYY-NNN`                                           |
| 演练类型               | 备份恢复 / 迁移升级 / 回滚 / 故障转移 / readiness / 其他 |
| 计划与实际时间（UTC）  | 计划：；实际：                                           |
| 环境                   | 本地 / 隔离测试 / 预发布 / 生产（需批准）                |
| 应用 commit / 镜像摘要 |                                                          |
| 数据库版本与迁移数     |                                                          |
| 责任人                 |                                                          |
| 审批人                 |                                                          |
| 参与者                 |                                                          |
| 变更或演练记录         | 受控链接                                                 |

- RTO 目标（如已有正式目标）：

## 前置检查

- [ ] 已确认备份点、来源版本、加密密钥和访问权限。
- [ ] 已确认隔离恢复目标，不覆盖唯一生产库。
- [ ] 已记录当前 readiness、健康状态、迁移版本和关键业务摘要。
- [ ] 已准备回滚脚本、前一版本制品和配置快照。
- [ ] 已确认日志、指标、审计和通知渠道。
- [ ] 已确认参与者、升级路径和停止条件。

## 审批与复核

- [ ] 责任人确认记录完整。
- [ ] 审批人确认结果和残余风险。
- [ ] 需要更新的运行手册、发布门禁或告警已列入任务。
