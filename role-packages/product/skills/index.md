# 产品角色包 · 技能索引

本包提供三个技能。宿主应优先加载与当前任务匹配的那一个，不要一次全读。

| 技能             | 做什么                             | 何时用                         |
| ---------------- | ---------------------------------- | ------------------------------ |
| `clarify-intent` | 把模糊诉求整理成目标、边界与未知项 | 需求刚提出、下游回问、范围不清 |
| `write-prd`      | 基于已确认理解产出 PRD             | 理解已确认、需要出稿或修订     |
| `map-acceptance` | 把 PRD 拆成可判定的验收            | PRD 草稿完成、验收需修订       |

## 使用顺序

```
clarify-intent → write-prd → map-acceptance
```

前一步的产出是后一步的输入。跳过 `clarify-intent` 直接写 PRD，通常会把未确认的假设写进需求。

## 交接

- 理解 → `understanding.md`，交产品确认。
- PRD → `prd.md` + `acceptance.yaml`，交评审批次。
- 验收 → 由 QA 做可测性签核后再发布。
