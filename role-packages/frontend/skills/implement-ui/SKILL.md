# 实现界面

## 何时用

- 设计规格与契约就绪，任务已认领。
- 需要在既有页面上做增量改动。

## 步骤

1. 取上下文：PRD 验收、设计规格、契约、项目规范。
2. 按设计实现布局与交互，复用现有组件。
3. 补齐状态：正常、空、错误、加载、权限受限。
4. 接契约：替换 mock，处理错误码与重试。
5. 自测：交互、边界、响应式、可访问性。
6. 产出 `impl.md` 后半部分。

## 规则

- 不改验收标准：实现与 PRD 冲突时发 `NEEDS_CLARIFY`。
- 不擅自改设计：偏离要在 `impl.md` 写明原因。
- 不绕过契约：字段名与错误码以契约为准。
- 注释只写「为什么」；TODO 带负责人和期限。

## 自测清单

- [ ] 五种状态都有实现。
- [ ] 错误码有对应提示，不是统一「出错了」。
- [ ] 关键交互可用键盘完成。
- [ ] 小屏与长文本不破版。
- [ ] 无 console 报错与未处理 Promise。

## 交接

提交代码（commit 带需求编号）+ `impl.md`，交评审。
