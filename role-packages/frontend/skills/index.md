# 前端角色包 · 技能索引

| 技能               | 做什么                            | 何时用               |
| ------------------ | --------------------------------- | -------------------- |
| `consume-contract` | 读契约与设计，出实现方案、建 mock | 契约已发布、设计可用 |
| `implement-ui`     | 按设计实现界面与交互并自测        | 设计规格与契约就绪   |

## 使用顺序

```
consume-contract → implement-ui
```

前端不必等后端写完：契约一发布就能建 mock 开工，等后端联调时只换数据源。

## 交接

- 方案 → `impl.md` 前半部分（改动范围、组件、接口依赖）。
- 实现 → 提交 + `impl.md` 后半部分（自测、遗留项）。
