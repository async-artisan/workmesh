# 测试角色包 · 技能索引

| 技能             | 做什么                     | 何时用                         |
| ---------------- | -------------------------- | ------------------------------ |
| `derive-cases`   | 把验收转成用例与评测集     | PRD 发布后，代码未就绪也可开始 |
| `run-evals`      | 执行评测并分类失败         | 有可运行构建或环境             |
| `report-defects` | 把失败归因为缺陷并跟踪回归 | 评测失败且判定为缺陷           |

## 使用顺序

```
derive-cases → run-evals → report-defects
```

用例可以先写，执行要等代码。这个顺序让测试与开发并行，而不是串在最后。

## 交接

- 用例 → `cases.yaml`，交产品确认覆盖。
- 评测 → `evals.yaml` + 结果，交评审。
- 缺陷 → `defect.md`，回传开发并在修复后回归。
