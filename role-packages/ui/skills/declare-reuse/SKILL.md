# 声明复用

## 何时用

- 需求与既有页面/组件高度相似。
- 只涉及文案、数据或权限变化，不新增视觉状态。

## 步骤

1. 在设计系统与既有页面中找到可复用的对象。
2. 逐项比对：布局、组件、交互、状态是否完全覆盖。
3. 写差异：哪些字段、文案、权限不同，是否需要局部扩展。
4. 给指针：组件名、页面路径、设计稿链接。
5. 产出 `reuse-declaration.md`。

## 规则

- **复用不是「不设计」**：必须说清复用什么、差在哪。
- 指针要能被前端直接打开，不能只写「参考设置页」。
- 差异超过三处或涉及新交互，改走 `write-design-spec`。
- 复用导致验收无法满足时，明确写出冲突，不硬套。

## 交接

`reuse-declaration.md` 交前端；前端据此实现，不需要重新出稿。
