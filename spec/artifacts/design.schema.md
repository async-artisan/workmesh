# 设计工件规范（kind: DESIGN）

允许扩展名：`.md .png .jpg .jpeg .svg .fig .pdf`。交付时 `--kind DESIGN`。

## 内容要求

```markdown
# <页面/功能>设计（YFF-001）

## 页面与流程

## 状态清单（正常 / 空 / 错误 / 加载 / 权限受限）

## 交互与边界条件

## 响应式与可访问性约束

## 对验收标准的覆盖说明
```

## 自检项

| 检查项     | 要求                     |
| ---------- | ------------------------ |
| `exists`   | 文件真实存在             |
| `fileType` | 扩展名属于 DESIGN 白名单 |
| `notEmpty` | 文件非空                 |
| `anchor`   | 路径或摘要含需求编号     |

## 约定

- 设计文件命名含需求编号：`YFF-001-<页面>.fig`；
- 与既有设计规范不一致处必须写明理由；
- 只上传指针，设计正文与设计文件本体留在本地。
