# 发布工件规范（kind: RELEASE）

允许扩展名：`.md`。交付时 `--kind RELEASE`。

## 内容要求

```markdown
# 发布记录（YFF-REQ-123）

## 版本号与时间

## 环境

## 影响需求

- YFF-REQ-123

## 灰度与回滚方案

## 冒烟结果
```

## 自检项

| 检查项     | 要求                                  |
| ---------- | ------------------------------------- |
| `exists`   | 文件真实存在                          |
| `fileType` | 扩展名属于 RELEASE 白名单（仅 `.md`） |
| `notEmpty` | 文件非空                              |
| `anchor`   | 路径或摘要含需求编号                  |

## 约定

- 必须列出本次影响的需求编号，否则无法与需求建立追溯；
- 回滚方案缺失视为 DoD 未完成；
- 签字在平台内完成：`workmesh sign <taskId> --comment "已发布并冒烟"`。
