# 设计覆盖清单

- [ ] 每条界面相关的验收都有对应界面表现。
- [ ] 五种状态（正常/空/错误/加载/权限受限）都有定义。
- [ ] 交互的异常路径有处理方式。
- [ ] 边界（长文本、超长列表、小屏）已考虑。
- [ ] 优先复用现有组件，新组件有理由。
- [ ] 与设计规范的偏离已写明原因。
- [ ] 复用声明给出了可打开的指针，不是口头描述。
- [ ] 设计稿命名含需求编号。
- [ ] 前端拿到规格后不需要再问「这里怎么显示」。
- [ ] 验收 key 与界面的对应关系已列出。

## 交付前最后三问

1. 前端只看这份规格，能不能不问你直接实现？
2. 空数据和接口报错时，界面长什么样？
3. 这页在小屏上还成立吗？
