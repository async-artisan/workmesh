# UI 角色包 · 技能索引

| 技能                | 做什么                   | 何时用                         |
| ------------------- | ------------------------ | ------------------------------ |
| `write-design-spec` | 产出页面、状态、交互规格 | 新页面、新交互、视觉变更       |
| `declare-reuse`     | 声明复用现有组件或模式   | 可复用既有设计、无新增视觉状态 |

## 先判断走哪条

```
需要新视觉/新交互？ ── 是 ──► write-design-spec
        │
        └── 否 ──► declare-reuse（给指针，不重新设计）
```

大部分需求属于复用：先查设计系统，找不到再动笔。

## 交接

- 新设计 → `design-spec.md`，交前端与产品确认。
- 复用 → `reuse-declaration.md`，给前端明确的组件与页面指针。
