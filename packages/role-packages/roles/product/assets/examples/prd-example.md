# PRD 示例：支持本地模型接入

> 需求编号：YFF-003 · 版本：v1 · 状态：已发布
> 依据理解：understanding v1

## 1. 背景

企业客户要求模型调用不出内网。当前只支持云端模型，导致两个在谈客户无法采购。

## 2. 目标

用户可以在设置页切换到本地模型，切换后新建的对话使用本地模型，且不需要重启应用。

## 3. 范围

**做**

- 设置页新增「模型来源」选项：云端 / 本地。
- 本地模式下校验地址可达，不可达时给出明确提示。
- 切换只影响新对话，已有对话保持原模型。

**不做**

- 不做本地模型的部署与运维。
- 不做多本地模型负载均衡。

## 4. 方案要点

- 本地地址只允许内网段，禁止公网地址。
- API key 在本地模式下可留空，但界面必须区分「未配置」与「配置错误」。

## 5. 依赖与约束

| 类型 | 内容                           | 影响       |
| ---- | ------------------------------ | ---------- |
| 契约 | 模型调用统一走 provider 适配层 | 不新增直连 |
| 合规 | 本地地址不得外发               | 日志脱敏   |

## 6. 验收

见 `acceptance.yaml`。特别说明：A1 与 A2 的判定需要在同一会话内连续切换两次。
