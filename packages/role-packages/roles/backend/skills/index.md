# 后端角色包 · 技能索引

| 技能               | 做什么                                | 何时用                 |
| ------------------ | ------------------------------------- | ---------------------- |
| `design-contract`  | 从 PRD 推导接口契约、数据变更与错误码 | PRD 就绪、开工前       |
| `implement-change` | 按契约实现并自测                      | 契约已发布、任务已认领 |
| `attach-evidence`  | 收集提交级证据并交付                  | 实现完成、准备交付     |

## 使用顺序

```
design-contract → implement-change → attach-evidence
```

契约是并行开发的支点：前端、测试都靠它开工。**契约没发布之前，不要开始写实现**，否则前端只能猜。

## 交接

- 契约 → `contract.md`，交前端、QA、运维消费；变更走平行变更。
- 实现 → `impl.md` + 提交引用，交评审。
- 交付 → `ArtifactSet` + `checks[]`，交人工验收。
