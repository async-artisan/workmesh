# 运维角色包 · 技能索引

| 技能              | 做什么                           | 何时用       |
| ----------------- | -------------------------------- | ------------ |
| `prepare-release` | 发布计划：依赖、顺序、灰度、监控 | 进入发布候选 |
| `rollback-plan`   | 回滚方案并验证可执行             | 发布前       |
| `smoke-check`     | 生产冒烟并给结论                 | 发布后       |

## 使用顺序

```
prepare-release → rollback-plan → 发布 → smoke-check
```

回滚方案必须在发布**之前**验证，发布后再想怎么退已经晚了。

## 交接

- 计划 → `release.md`，交发布评审。
- 回滚 → `rollback.md`，发布前演练一次。
- 冒烟 → `smoke.md`，交发布确认。
