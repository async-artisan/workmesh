- [ ] 灰度策略与放量条件已写。
- [ ] 监控项、阈值、查看位置已写。
- [ ] 回滚触发条件已写，且可判定。
- [ ] 回滚方案已演练，耗时已知。
- [ ] 不可逆操作有补偿方案。
- [ ] 冒烟项覆盖本次验收。

- [ ] 外部系统不可用时，降级方案已写。
